# ThingsPanel MCP 0.1.11

## Changes

- All 14 focused device, telemetry, dashboard, and control tools return typed MCP `structuredContent` with `ok`, `summary`, `data`, and `error` fields.
- Added `get_device_command_status(message_id)` for the backend command receipt endpoint. `send_device_command` exposes the returned `message_id` when available.
- Added the command receipt endpoint to the generated API inventory.
- Command acceptance and device execution remain separate states. This release does not add a pre-operation confirmation argument to the focused control tools.

## Validation

Release validation results are recorded when the package is built and tested from the release commit.
